# Zivtech Writing Style Skill

A Claude Code skill that provides Zivtech brand voice, tone, and writing style guidelines.

## When to Use

This skill should be used when creating any content for Zivtech:
- Blog posts
- Proposals
- Case studies
- Website copy
- Marketing materials
- Social media
- Client communications

Also use when the user asks to:
- Write in Zivtech's voice
- Apply Zivtech brand guidelines
- Create content that should sound like Zivtech

## What It Provides

- Brand voice (Expert, Direct, Approachable)
- Tone and key messaging principles
- AI-related messaging guidelines
- Brand values and personas (5 audience types)
- Writing style manual (AP Style with exceptions)
- AI terminology guidelines
- Words and patterns to avoid
- General writing rules and resources
